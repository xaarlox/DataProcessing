# Моделювання системи попиту та пропозиції електроенергії
Цей проєкт реалізує динамічну математичну модель ринкової рівноваги (модель Еванса/модель Вальраса-Еванса-Самуельсона) для ринку електроенергії та порівнює її з методом машинного навчання для трендової екстраполяції.

## Постановка задачі
Реалізуйте динамічну модель попиту та пропозиції електроенергії з використанням диференціальних рівнянь. Порівняйте з методом трендової екстраполяції.

## Аналіз проблеми та підхід до рішення
Прогнозування цін на складних ринках вимагає розуміння внутрішніх механізмів системи. Статистичні методи прогнозування часто опираються лише на попередню динаміку цифр, ігноруючи економічні закони. Використання моделі Еванса дозволяє описати зміну ціни $P(t)$ як неперервний процес, що залежить від різниці між попитом $Q_d$ та пропозицією $Q_s$.

**Етапи реалізації**:
1. *Математичне формулювання*: Задання лінійних функцій попиту та пропозиції, а також диференціального рівняння швидкості зміни ціни:
   $\frac{dP}{dt} = \gamma (Q_d - Q_s)$
2. *Чисельне розв'язання (ЗДР)*: Розрахунок траєкторії ціни в часі від початкового стану до моменту ринкової рівноваги.
3. *Трендова екстраполяція*: Навчання моделі лінійної регресії на першій третині згенерованих даних (імітація "історичних даних") та прогнозування на весь період.
4. *Візуалізація та аналіз*: Побудова графіків та консольних таблиць для наочного порівняння двох підходів.

## Використані бібліотеки
+ **numpy** - для швидкої генерації масивів часової шкали та роботи з векторами даних.
+ **scipy (solve_avp)** - ключовий інструмент для чисельного розв'язання звичайних диференціальних рівнянь. Дозволяє симулювати динаміку ціни крок за кроком.
+ **scikit-learn (LinearRegression)** - для реалізації машинного навчання та побудови трендової екстраполяції.
+ **matplotlib** - для побудови наочних графіків, що демонструють розбіжність моделей з плином часу.
+ **prettytable** - для форматування та виводу числових результатів симуляції у вигляді зручної консольної таблиці.

## Особливості реалізації
1. **Динамічна модель (ЗДР)**

   У функції `price_derivative` реалізовано економічну логіку реакції ринку: якщо попит перевищує пропозицію (дефіцит), похідна ціни є додатною і ціна зростає. Швидкість цієї реакції регулюється коефіцієнтом $\gamma$.

2. **Обмеження навчальної вибірки**

   Для чистоти експерименту лінійна регресія не "бачить" усієї картини. Змінна `train_size` обмежує її знання лише першою третиною симуляції, де ціна стрімко зростає через початковий дефіцит.

3. **Аналітична перевірка**

   У коді реалізовано математичний розрахунок ідеальної рівноважної ціни $P = (a + c) / (b + d)$, яка використовується як еталонна лінія на графіку для верифікації правильності роботи диференціального рівняння.

Аналіз графіка та консольного виводу яскраво демонструє критичні відмінності у двох підходах:
- **Динамічна модель (зелена лінія)**: Поводиться згідно з економічними законами. Стартуючи з низької ціни, система відчуває різкий дефіцит електроенергії, що викликає стрімке зростання ціни. Проте, наближаючись до рівноважної позначки, зростання сповільнюється - попит падає, ринок насичується і стабілізується.
- **Трендова екстраполяція (помаранчева лінія)**: Алгоритм навчився на початковому етапі стрімкого зростання. Оскільки це лінійна модель, вона припускає, що ціна зростатиме нескінченно. Алгоритм не знає про існування попиту та обмеження купівельної спроможності.

**Загальний висновок**:

Метод трендової екстраполяції може бути корисним лише для дуже короткострокових прогнозів. На довгій дистанції він дає абсолютно хибні результати для складних економічних чи фізичних систем, оскільки ігнорує їхні внутрішні обмеження та прагнення до балансу.

Натомість, математичне моделювання за допомогою диференціальних рівнянь виявляється значно надійнішим та адекватнішим інструментом. Воно відтворює саму механіку взаємодії елементів, дозволяючи точно передбачити як швидкість зміни ціни, так і точку її остаточної стабілізації.
